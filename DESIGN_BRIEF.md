# Задание на дизайн: приложение «Дневник»

Исполнитель: Codex. Проект: Android, Kotlin + Jetpack Compose (Material 3), телефоны Realme (Realme UI, Android 8+).

## Что нужно сделать

Разработать и внедрить дизайн приложения: экраны списка, редактора, блокировки и настроек. Сейчас они работают, но оформлены минимально (стандартные компоненты Material 3 и палитра из `ui/Theme.kt`).

## Ограничения (обязательно)

- Приложение полностью локальное. Не добавлять сетевые библиотеки, веб-шрифты, аналитику и удалённые картинки. Единственное обращение к сети — `data/Updater.kt`.
- Шрифты и иконки — только внутри APK (например, положить в `res/font`). Для иконок хватает `material-icons-core`; если нужен набор шире, рисовать свои векторы в `res/drawable`.
- Не менять логику в `data/` и `MainViewModel.kt`. Менять можно `ui/*`, `ui/Theme.kt`, ресурсы и, при необходимости, сигнатуры Composable.
- Сохранить функции: заметки и дневник, поиск и фильтр, PIN и отпечаток, автосохранение (5/10/15 мин/выкл.), резервная копия, окно обновления.
- Тёмная и светлая темы обязательны. Контраст текста не ниже 4.5:1, область нажатия не меньше 48×48 dp, у иконок без подписи есть `contentDescription`.
- Анимации умеренные (150–300 мс), учитывать отключение анимаций в системе.
- Текст интерфейса — русский, правки только через строки в коде/ресурсах без смены смысла.
- Версию и `versionCode` не менять без запроса владельца; правила — в `../VERSIONING.md`.

## Направление

Тёплый «бумажный» дневник: кремовый фон, коричневый акцент (`#92400E`), спокойная типографика, мягкие тени (стиль Soft UI Evolution). Рекомендации и локальный поиск — скил `../ui-ux-pro-max-skill/SKILL.md` (запуск: `python ../ui-ux-pro-max-skill/scripts/search.py "<запрос>" --domain ux`).
