# Дневник

Личные заметки и дневник для Android (проверка в расчёте на Realme UI). Kotlin + Jetpack Compose + Room, без интернета и аккаунтов.

Версия: **2026.4.4.4** (альфа). `versionCode` — 3.

## Что есть

- Заметки и записи дневника: создание, правка (сохраняется при выходе), удаление, поиск, фильтр.
- Блокировка по PIN (PBKDF2-хеш с солью) и отпечатку; повторная блокировка через 20 секунд вне приложения.
- Скриншоты и превью в списке недавних отключены (`FLAG_SECURE`), автобэкап Android отключён.
- Резервная копия в JSON через системный выбор файла: сохранить и загрузить (дубликаты пропускаются).
- Светлая и тёмная темы, палитра из UI UX Pro Max (тёплый коричневый на кремовом).

## Сеть и автосохранение

- Приложение полностью локальное. Единственный сетевой запрос — проверка обновлений при открытии: список релизов репозитория на `api.github.com` (разрешён только HTTPS, никаких данных не отправляется). Приложение ничего не скачивает само, а лишь предлагает открыть страницу релиза.
- Репозиторий задаётся в `app/build.gradle.kts`, поле `UPDATE_REPO` (`владелец/имя`). Пока оно пустое, проверка выключена.
- Автосохранение: каждые 5 минут (в настройках 10, 15 или «Выкл.») сохраняется открытая запись и создаётся копия всех записей в закрытой папке приложения (последние 5). Работает, пока приложение открыто: фоновых служб нет, чтобы Realme не убивал их и не расходовался заряд.

## Сборка

Нужны JDK 17 и Android SDK 35 (путь к SDK — в `local.properties`, файл не коммитится). Можно открыть папку `dnevnik` в Android Studio или собрать из терминала:

```
gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Статус проверки

Debug-сборка `assembleDebug` проходит, APK подписан и проверен `apksigner`, версия и разрешения (`USE_BIOMETRIC`, `INTERNET`) сверены через `aapt2`. **На телефоне приложение пока не запускалось**: экраны, блокировка, отпечаток и автосохранение ещё не проверены вживую. Ключ подписи `signing/debug.keystore` хранится только у владельца и в репозиторий не входит: обновлять установленное приложение можно только APK, подписанным тем же ключом.
